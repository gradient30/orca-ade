# 隐私与遥测 {#privacy-telemetry}

本页说明我们在打包的 Orca 构建中收集哪些匿名产品用量遥测、我们绝不收集什么，以及如何退出。

## 摘要 {#summary}

- **匿名。** 事件用存储在你本机上的随机 ID 作为键。不收集账号、邮箱、IP 地址或用户名。
- **无内容。** 我们从不传输文件内容、prompt、Agent 输出、终端输出、仓库名、分支名、URL、路径或提交信息。
- **以下情况始终关闭：** 设置了 `DO_NOT_TRACK=1` 或 `ORCA_TELEMETRY_DISABLED=1`。

## 我们收集什么 {#what-we-collect}

每个事件还会附带基本的构建和平台信息：Orca 版本、操作系统（例如 `darwin` / `win32` / `linux`）、CPU 架构、粗粒度 OS 发行字符串、发布通道（`stable` 或 `rc`），以及上面说的匿名本地 ID。没有主机名，没有用户名，没有 IP。

我们观察的行为类别：

- **生命周期** — 应用何时打开。用于估算日活、周活和月活用户。
- **仓库与工作区** — 你何时添加仓库或创建工作区。我们记录你 _如何_ 做的（例如文件夹选择器 vs. clone URL；命令面板 vs. 拖放），从不记录仓库名、URL、路径、分支名或任何自由文本。创建工作区时还会记录耗时，以及这段时间如何分到各步骤；是否复用了 Orca 事先准备好的 checkout（若复用：需要哪种 reset、由什么准备、准备花了多久、闲置等了多久；若未复用：一个固定原因码）；创建失败时停在哪一步。另有粗粒度上下文：来自 Orca 窗口，还是 CLI、手机或 Agent 界面；Git 跑在本地、WSL 还是 SSH；分桶后的 worktree 数量；仓库跟踪文件数的分桶；当时还有多少其他创建和已准备 checkout 任务在跑；仓库是否有 post-checkout hook（从不记录其内容）。
- **Agents** — 你使用哪些 Agent 及其 token 数量。从不记录 prompt 或 Agent 输出。
- **Agent 错误** — 粗粒度错误类别以及涉及哪种 Agent。我们从未看到原始错误消息或堆栈跟踪；每次事故的细节留在你本机的本地诊断跟踪文件里，只有你明确分享诊断包时才会到达 Orca。
- **设置** — 你何时切换一小份白名单里的功能开关或 UX 偏好。我们记录哪个偏好变了、它是布尔还是枚举，从不记录任何自由文本设置的原始值。
- **隐私控制** — 你何时选择加入或退出遥测，以便我们从聚合数据判断同意 UI 是否在工作。
- **SSH 远程运行时** — 每个应用会话、每台 SSH 主机一次：Orca 在该主机上用了哪种运行时、以及为什么。包括粗粒度主机事实（操作系统、CPU 架构、C 库家族与 glibc 次版本，以及 Orca 在其上运行时宿主的 Node.js 主版本）、拒绝类别、是否上传过运行时，以及粗粒度耗时分桶。从不包含主机名、用户名、路径或原始错误文本。

字段包括固定枚举值、版本字符串、数值计数与修订号，以及随机本地 ID。会话 ID 允许将同一会话的多次 token 汇总关联起来；它们是伪匿名的。任何 UI 输入里的自由文本都不会离开你的机器。

## 我们从不发送什么 {#what-we-never-send}

- 没有文件路径、仓库名、分支名、URL、提交信息或当前工作目录。
- 没有 Agent prompt、回复或终端内容。
- 没有原始错误消息或堆栈帧。每次事故的错误上下文留在你本机的本地诊断跟踪文件里，只有你明确分享诊断包时才会到达我们。
- 没有用户账号信息（Orca 没有账号系统）。
- 没有 IP 地址，也没有精确 geoip；国家是从请求推导出的唯一地理信号。
- 没有与你的匿名 ID 绑定的供应商侧用户档案。

## 如何退出 {#how-to-opt-out}

你可以用三种方式禁用遥测。任意一种都足够；它们可以叠加。

1. **在应用里。** Settings → Privacy → 把 "Share anonymous usage data" 关掉。更改立即生效并持久保存。

> **图示** Settings → Privacy — 关闭 'Share anonymous usage data' 以禁用遥测。

2. **`DO_NOT_TRACK=1`** — 社区标准环境变量。禁用该次启动的传输。取消设置后，下次启动会恢复你已存储的偏好。
3. **`ORCA_TELEMETRY_DISABLED=1`** — Orca 专用的关闭开关，语义与 `DO_NOT_TRACK` 相同。

## 数据去向 {#where-the-data-goes}

- **供应商：** PostHog Cloud，**United States** 区域。
- **保留期：** PostHog Cloud 按其定价页的套餐级默认。我们不设置自定义保留窗口。
- **访问：** 项目成员仅限少数 Orca 维护者。
